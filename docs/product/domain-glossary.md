# Glossário de domínio

| Termo | Significado |
|---|---|
| Simulação | Cálculo preliminar das condições de um crédito solicitado. |
| Renda mensal | Valor informado como renda mensal do cliente. |
| Valor solicitado | Principal que o cliente deseja simular. |
| Parcela mensal | Valor calculado para cada pagamento. |
| `AVAILABLE` | A parcela está dentro do limite de 30% da renda. |
| `UNAVAILABLE` | A parcela ultrapassa o limite de 30% da renda. |
| Proposta | Etapa futura posterior à simulação. |
| Contrato | Etapa futura de formalização da operação. |
| Parceiro | Participante externo que será tratado pelo módulo `partners` no futuro. |
| Tenant | Contexto de isolamento futuro; ainda não é aplicado nesta fase. |
